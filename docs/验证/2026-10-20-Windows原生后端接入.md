## 根因与修复

### 兼容授权不再与工作区内容授权混用

第一轮的 Git、NUL 和原生 realpath 失败，不能靠 Node 启动通过来忽略。本批使用独立兼容 capability SID，准备 NT DOS 对象名称查询、MountPointManager 读取、NUL 读写及非继承的目录元数据读取。工作区内容仍授给每次执行唯一的 package SID，两个并发组合不共享文件内容授权。

磁盘根目录和祖先只得到元数据权限，不允许列目录、读取文件内容或写入，不向 `All Application Packages` 授权。没有新建 Windows 账户、服务、计划任务、网络规则或修改设备完整性标签。

微软的 [AppContainer 说明](https://learn.microsoft.com/en-us/windows/win32/secauthz/implementing-an-appcontainer)、[宿主准备文档](https://github.com/microsoft/mxc/blob/main/docs/backends/process-container/host-prep.md) 及 [路径问题记录](https://github.com/microsoft/mxc/issues/694) 提供机制和排查依据；本批以本机 Win32 对照及实际执行结果验收。未采用仅按账户匹配 WFP 作为严格断网依据；Anthropic [Windows alpha 已知限制](https://github.com/anthropics/sandbox-runtime#windows-alpha) 明确列出匿名和派生令牌问题。

### 真实 Git、路径与 PowerShell 工作目录

只读 / 可写、私有文件、另一个项目、并发不同授权、运行时 junction 与文件 DACL 写入负向用例均通过。Git 的版本、建仓、状态和 Diff 已实际执行；原生 NUL 打开和 Node native realpath 对照通过。

PowerShell 在隔离内可能初始定位到自己的程序目录。本批命令入口显式以转义后的 `Set-Location -LiteralPath` 进入工作区；SDK 的相对路径命令以及带中文、空格和单引号的工作区已通过。工具名保留 `bash`，描述、短提示和运行环境均明确为 Windows PowerShell。扩展路径先统一再比较受保护目录；UNC 程序在宿主访问前拒绝，当前仅支持本机磁盘工作区。

文件 worker 在 Windows 使用 Job Object 监督，不再通过 Node 派生带管道的监督进程；路径检查使用已验证的 native realpath，并正确处理 Windows 分隔符。Linux 容器继续使用原监督路径。

### Node 管道仍未通过

当前包内 Node 22.19.0 使用 libuv 1.51.0；宿主 Node 24.19.0 使用 1.52.1。AppContainer 内 `execFileSync` 等新建子进程管道的操作超时；继承标准句柄的后代创建与回收通过。

[Node 官方问题 #66374](https://github.com/nodejs/node/issues/66374) 描述 libuv 对命名管道名称的 AppContainer 兼容问题，以及上游 1.53.0 的相关修复。截至本批查询，不能假定当前正式 Node 包已带修复。因此保留 19/20 的非零结果，界面和模型上下文均披露限制，没有修改全局 Node 二进制或以解除 AppContainer 代替修复。

下一批应评估固定版本、可复现的 Node/libuv 修复构建与实际 SDK / 安全回归，再决定是否随包提供；不把当前预览升格为通用命令环境。

## 生命周期与资源

- 创建日志并同步落盘后才创建身份；日志校验 profile 名称与派生 SID 的对应关系。
- 全局命名互斥量串行合并 ACL，撤销只移除唯一身份的条目；元数据修改只操作目录自身，避免递归传播，保留继承控制字段。
- 每个执行持有租约；重放日志跳过活动执行。取消、控制器 EOF、强杀 helper、前台正常退出的真实后代回收均通过。强杀保留日志再由宿主恢复，不能等同于真实关机已验收。
- Job 限制 32 个进程、单进程与整个 Job 提交内存各 1 GB、120 秒；输出有 2 MB 上限。团队 CPU / 内存 / 费用硬预算和资源压力测试仍待后续。
- 原生 Node 缓存在 Tao 数据目录下，按宿主二进制 SHA-256 核对，先同步临时文件再原子替换，失败允许下次重试。HOME、用户配置与临时变量重定向到本次工具目录，显式允许的凭据才传入。

网络验证使用有宿主成功对照的回环 TCP 监听，并核对接入计数；AppContainer 普通连接和匿名线程令牌连接未到达。该证据不等于已认证所有协议、系统服务代连与公网场景。
