# 0.2.0 发布前检查与验收

本轮用户确认版本为 **0.2.0**，授权按安全检查、编译与安装验收的顺序推进。Windows 原生执行后端继续标注预览。以下检查均在 Windows 11 23H2 x64 开发机进行，不代表 Windows 10、干净电脑、跨用户及任意第三方程序都已验收。

## 发现与修复

1. **工作区已有硬链接会泄露工作区外同一文件的内容。** 首轮合成用例确实未被拒绝，见 `.tao-release-cache/windows-executor-lab/boundary-run-74tSRG/report.json`。现在预检和实际授权时均检查句柄的链接数，拒绝多硬链接文件；需要复制成独立文件。没有以扩大授权或回退本机绕过检查。
2. **递归 ACL 传播不适合作为动态目录边界。** 授权现逐级通过固定父目录句柄调用 `NtOpenFile`，使用 `OBJ_DONT_REPARSE`；每个对象使用 `SetKernelObjectSecurity` 更新 ACL，不让 `SetSecurityInfo` 隐式递归传播。清理只删除自己 SID 的显式/继承 ACE，保留其他 ACE；遇到子目录链接时只清理链接对象，不进入目标。新文件仍通过父目录 ACE 继承本次执行权限。
3. **共享兼容授权需要活动执行保护。** ProgramData 中的管理员所有、受保护锁文件由所有原生执行持有共享读取句柄，管理员准备/移除需要独占句柄；进程退出或崩溃会自动释放。首轮仅请求元数据权限的句柄没有形成预期互斥，已在实测中发现并改为 `GENERIC_READ`，保留 `setup-run-rYM4Rc/report.json` 的失败记录。
4. **移除与升级。** 定制界面增加“移除本机原生授权”；移除会影响本机全部 Tao 原生组合，活动工具会阻止操作。MSI 明确卸载时执行包内嵌入的辅助组件，避免以管理员身份运行安装目录中可能被改写的 exe；升级旧包的移除阶段跳过共享授权清理。清理只处理专用 SID，不删除工作区、会话、配置、账户或防火墙规则。
5. **管理员授权取消。** 桌面入口与开发脚本识别 Windows 1223 取消码并提供可重试提示；拒绝不会回退本机。实际 UAC 初始化、移除和恢复已执行；真实用户点击“取消”和重启仍另列人工验收，不能用代码分支检查替代。
6. **资源检查。** MSI 必须包含原生 helper、兼容 Node 构建清单/npm/npx、执行与压缩策略模块；文件表之外还验证嵌入 helper 的卸载动作、执行方式、顺序和跳过升级条件。

本批未声称能抵御与宿主同权限的恶意程序、管理员或宿主主动移动/修改已授权文件所造成的一切竞争。原生预览不支持已有 reparse point、硬链接和超过 10000 项的授权树，固定宿主路径/工作区外依赖及盘符不足也可能被拒绝。目录及元数据竞争仍需更多压力测试。
