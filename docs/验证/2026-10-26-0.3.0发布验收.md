# Tao 0.3.0 发布验收

2026-10-26 用户明确授权打包发布新版本。本批纳入 0.2.0 后已完成的输入框、联网、MCP、Skills、文档读取、能力页面与 Tao 基础镜像改动；不部署搜索服务、不发布 Docker 镜像。

## 验证依据

开发阶段的工具、权限、协作、Runtime 模拟链路、24 项 Rust 测试、类型构建及界面回归已经通过；真实 Docker 构建与隔离执行、浅深色和窄窗口详情见[能力页面与镜像验收](./2026-10-26-能力页面与Docker镜像.md)。既有批次说明保留当时“未打包”的含义，本记录补充 0.3.0 实际安装包结果。

## 源码与构建检查

- 版本同步至 0.3.0，更新 README、随包帮助及发布说明。
- 扩充 MSI 必需文件检查，包含能力状态模块、镜像准备模块与完整 Docker 构建配方。
- `npm run check`、`npm run test:agents`（含完整 Runtime 和 24 项 Rust）、`npm run test:ui` 全部通过；本轮完整 agents 命令在受限测试环境外一次通过，未读取真实用户配置。
- `npm run tao:release -- 0.3.0` 完成资源准备/哈希验证、前端和 Rust Release 编译，生成 MSI。首轮为同步随包帮助文档主动中断，最终构建包含 0.3.0 帮助内容；没有沿用旧 MSI。
- 暂存内容检查：91 个源码/文档文件，无构建目录或用户数据文件，无所检查凭据格式的匹配；此检查不替代第三方代码审查。

## 验收边界

在 Windows 11 开发机验证，模型/搜索/MCP/GitHub 调用链使用临时数据与本地模拟服务，不读取真实 Tao 配置。行政提取不是覆盖安装；没有声称本轮已验证用户现有安装升级、干净电脑、Windows 10、真实第三方搜索或 MCP、UAC 取消、明确卸载或重启。上一版用户整体试用结论不自动成为新版验收结论。

当前未配置代码签名。搜索仍需用户配置自己的服务；镜像由用户本地准备。已授权的发布不等于这些后续服务已部署。
