# Tao 标志：T·道

## 方向

按用户选定的参考图重绘为「T·道」：炭黑色圆角底承托暖白色的流动 T，横画末端略向上挑，竖画在底部回转，表达道路与流动。使用粗笔画和留白，保证小尺寸辨识度。

- 炭黑：`#17191b` → `#090a0b`
- 暖白：`#fcf6eb`
- 源文件：[public/tao.svg](../../public/tao.svg)
- 矢量路径为本项目设计，不依赖字体、外部图片或图像生成服务。

## 使用位置

侧栏与新对话欢迎页、浏览器 favicon、桌面程序图标共用同一个源设计。主界面仍使用现有主题和布局，不改动任务与权限行为。

桌面图标由 Tauri CLI 从 SVG 生成，当前项目使用的 16 个图标文件保存在 `src-tauri/icons/`。新增移动端输出无需纳入当前仓库。

```powershell
npm.cmd run tauri -- icon public/tao.svg --output .tao-release-cache/tao-icons
```

检查输出后，将其中与 `src-tauri/icons/` 现有文件同名的资源复制回该目录。修改源文件时需同步重新生成。

源码图标替换不会改变已经安装的旧版程序；任务栏、快捷方式和安装包图标需在下一次桌面构建与安装后验收。Windows 的图标缓存也可能延迟显示更新。
