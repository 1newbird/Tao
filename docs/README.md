# Tao 文档入口

Tao 的文档分为两类：

- `docs/项目手册/`：面向日常开发、发布、迁移和后续接手的统一手册。
- `docs/顶层设计.md`、`docs/设计方案.md`、`docs/总纲与路线图.md` 等：设计事实、能力映射和历史决策记录。

新接手项目时，建议按下面顺序阅读：

1. [项目手册入口](./项目手册/README.md)
2. [代码审查结论](./项目手册/00-代码审查结论.md)
3. [项目现状与功能清单](./项目手册/01-项目现状与功能清单.md)
4. [架构与顶层约束](./项目手册/02-架构与顶层约束.md)
5. [开发环境与本地运行](./项目手册/03-开发环境与本地运行.md)
6. [Windows x64 打包发布](./项目手册/04-Windows-x64-打包发布.md)
7. [安装部署与项目迁移](./项目手册/05-安装部署与项目迁移.md)
8. [用户数据与持久化](./项目手册/06-用户数据与持久化.md)
9. [后续开发约束与变更流程](./项目手册/07-后续开发约束与变更流程.md)
10. [常见问题与验证清单](./项目手册/08-常见问题与验证清单.md)

手册中的状态以当前代码审查为准。若手册、旧方案和代码不一致，应先在
`00-代码审查结论.md` 中记录差异，再更新相关文档。
