# Tao 文档入口

文档各有用途：

- [开发 TODO](./开发TODO.md)：当前有效待办、已交付能力、待专项验收与用户已确认批次。
- [项目手册](./项目手册/README.md)：当前使用、架构、开发、发布和迁移说明。
- [0.3.0 发布说明](./发布说明/0.3.0.md)及 [验收记录](./验证/2026-10-26-0.3.0发布验收.md)：版本交付与实际验证证据；[0.2.0 验收](./验证/2026-10-21-0.2.0发布验收.md)保留历史结论。
- [历史 TODO](./开发TODO-历史记录-截至2026-10-21.md)、`docs/顶层设计.md`、`docs/设计方案.md`、`docs/总纲与路线图.md` 等：历史方案、能力映射与决策来源；未勾选项或旧“未实现”描述不能直接作为当前开发清单。
