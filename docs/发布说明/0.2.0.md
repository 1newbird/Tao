# Tao 0.2.0

## 新增

- 组合级权限与统一工具执行接口，主代理和成员的有效权限取交集。
- 可选 Docker 沙盒与 Windows 原生沙盒预览；Windows 原生无需 Docker，提供管理员准备、状态检测及主动移除。
- Windows 随包兼容 Node/npm，支持已验证的子进程、TypeScript、esbuild 和 Vite 本地构建，不替换系统 Node。
- 自定义自动压缩的触发参数、保留量和摘要补充要求，主会话与成员分别应用组合快照。
- 长任务状态持久化、取消与结果保存恢复；Tao 图标、README 展示及轻量滚动条更新。

## 沙盒修复与检查

- 修复普通/扩展 Windows 路径混用导致相对路径错误。
- 拒绝已有硬链接与目录链接，避免授权到工作区外文件；逐对象句柄授权，清理不进入子目录链接目标。
- 并发执行、只读、断网、启动失败、取消和 helper 崩溃后的进程/盘符/ACL 回收已有本机回归。
- 共享原生授权有活动执行锁；MSI 升级保留授权，明确卸载使用内嵌辅助组件移除。

## 安装与限制

Windows x64 MSI，83.9 MiB。安装版包含 Node 和原生辅助组件，无需安装 Node/Rust；Docker 后端需另行准备 Docker 与镜像。本机命令工具仍依赖工具本身所需的外部程序。

Windows 原生继续标注预览：命令使用 PowerShell，始终离线，单次最多 120 秒；已有目录链接/硬链接、超过 10000 项的授权树、固定宿主路径或工作区外依赖可能被拒绝。Windows 10、跨用户、重启与长期压力仍待实机验收。
