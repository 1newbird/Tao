# Tao 0.1.4

Windows x64 正式版本，基于已发布的 0.1.3。本版本已完成自动验收，用户已确认试用效果正常并授权发布。

已于 2026-10-19 发布：[GitHub Release v0.1.4](https://github.com/1newbird/Tao/releases/tag/v0.1.4)。发布源码提交为 `69eaa56`，提供 MSI 与 SHA-256 校验文件。

## 新增与改进

- 智能体组合保存角色提示词、工具选择与权限、Skills 和模型设置；项目默认与会话快照分开，支持组合导入导出及工具库。
- 多智能体支持独立上下文委派、并发、同级定向通信、接续任务、共享任务板、依赖验收与有界重试。右侧成员入口可切换详情，支持独立查看窗口、补充说明和分范围停止。
- 新组合默认开启协作，未指定成员组合时使用继承配置的默认成员；旧组合和旧会话保留原开关。父子工具与权限取交集，普通工具页无需勾选协作工具。
- 默认上下文采用 `tao-context-v2`：角色、实际工具短索引、执行规则、工作说明、协作规则、按需文档和运行环境分层。替换角色保留平台规则，工具完整说明通过 tools 传递，避免重复。
- 可预览完整默认模板与当前草稿；会话“上下文”可查看首次记录的 SDK 输入。工具定义、系统指令和消息摘要分别展示，旧记录保持原样。
- 内置 `read_tao_doc` 按需读取工具、协作、权限和定制专题，文档随包提供。
- 统一 Markdown 表格、代码、列表和链接渲染；优化流式工作说明、历史阅读、右侧滚动及窄窗口布局。用户问题和助手回答均支持复制。
- 设置增加帮助与功能指南；加强用户数据原子保存、坏会话读取和 Runtime 错误诊断。

## 使用与升级

- 正式分发物为 Windows x64 MSI。普通用户无需安装 Node.js、Rust 或开发依赖；需有 WebView2、可用的模型服务和认证。
- 退出旧版 Tao 后运行新版 MSI。同产品升级标识及内容完整性在构建后检查；用户会话与设置存于用户目录，不随安装包分发。
- Bash 和自定义工具所需外部程序仍需可用；grep/find 依赖 rg/fd，在缺失时可能联网获取。
- 已有会话采用保存的组合快照；需要新设置时，在空闲会话选择组合或明确应用新版。验证新提示词请新建会话，不会覆盖旧上下文记录。

## 能力边界与验收

当前仅一层委派、单机单 Runtime；本轮主请求结束后回收未完成成员。多个成员共享工作区，无操作系统级沙盒。停止与重试不会回滚已发生的外部动作。组合级压缩编辑器、团队费用硬预算、跨轮常驻成员尚未提供。

源码已通过代码检查、UI 自动回归和隔离的真实 SDK + 本地模拟网关回归。最终 MSI 提取资源也已使用包内 Node 完成双路径启动和完整模拟链路验证；用户已确认本版本试用效果正常。此结果不代表所有模型、异常路径和干净电脑环境均已验收，专项清单继续跟踪。
