# Tao 0.3.1

修复用户消息气泡中多余的底部留白：隐藏的复制按钮不再占用气泡内部空间，短消息按内容自然撑开，长消息继续自动换行。

复制按钮位于气泡下方，悬停消息或键盘聚焦时显示；显示和复制操作不会改变气泡尺寸。

本版为 0.3.0 的界面修复补丁，沿用已有功能和配置。提供 Windows x64 MSI。
