# Tao 0.3.0

## 新增能力

- 联网搜索支持 Brave Search 和 SearXNG，公开网页正文可独立读取；结果保留来源链接，搜索摘要与正文明确区分。
- 接入远程 Streamable HTTP MCP：添加服务、测试连接、发现并选择工具，调用遵守组合权限和会话快照。
- Skills 技能库支持本地导入、组合选择、会话显式调用，以及公开 GitHub 仓库/目录预览与安装。对话安装可单独启用，每次安装仍需确认。
- PDF / DOCX 附件和本地文档文本读取，解析组件随包提供，无需 Office、Python 或在线转换服务。
- Tao 基础 Docker 镜像 `tao-runtime:0.1.0` 及设置页准备入口，包含 Node/npm、Python/pip/venv、Git、rg、curl、jq、压缩工具和 C/C++ 构建工具。

## 界面改进

- 联网检索、外部服务 MCP、Skills 拆为独立配置页，连接详情与添加入口按需展开。
- 聊天顶部增加当前会话能力摘要，分别说明搜索与网页读取状态；未配置、权限受限、待测试和本次测试结果明确区分。更换模型 API 不会自动获得搜索服务。
- 消息输入框随内容增高，达到上限后内部滚动；生成期间“立即调整 / 回答后继续”独立显示，修复选项遮挡。
- 整理功能手册、加载提示与浅深色/窄窗口布局。

## 安装与使用范围

Windows 10/11 x64 MSI，应用运行所需 Node 与后台资源随包提供。当前安装包未签名，Windows 可能提示未知发布者。Windows 原生沙盒继续标注预览，Windows 10、跨用户、重启及长期压力仍待实机验收。

- 搜索默认关闭，需要配置自己的 Brave 密钥或 SearXNG 实例；本版没有部署公共搜索服务，也不承诺安装即可搜索。网页读取可独立启用，但仍受联网策略限制，暂不支持登录或动态网页。
- MCP 第一版支持远程 Streamable HTTP，不含 stdio、OAuth、Resources/Prompts 或自动安装服务。
- GitHub 技能安装仅支持公开来源；安装前固定提交并检查文件，不执行附带代码、不自动装依赖、不覆盖同名目录，旧会话不会热加载。
- PDF 读取文本层，DOCX 读取正文与表格；扫描件 OCR、旧版 DOC 和文档生成尚未支持。
- Docker 为可选后端，需要 Docker Desktop 的 Linux 容器；首次点击准备按钮会按随包配方下载并在本机构建镜像，约占 867 MiB，实际取决于构建。镜像不内嵌 MSI、未推送公共仓库。Windows 原生及本机后端无需 Docker。
- 已有组合保留显式镜像选择，已有会话继续使用其配置快照；保存新组合后需应用新版或新建会话。
