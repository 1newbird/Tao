# Tao 用户数据与持久化

## 1. Tao Home

Tao 的用户数据根目录是：

```text
C:\Users\<用户名>\.tao
```

代码通过 Tauri 的用户目录定位逻辑创建它。它与项目目录和 Agent 工作区分离。

## 2. 当前主要文件和目录

```text
.tao/
├─ tao.json
├─ auth.json
├─ settings.json
├─ models.json
├─ runtime/
│  └─ profile.json       # 旧配置，迁移后保留
├─ agents/
│  └─ catalog.json       # 当前组合、工具库与项目默认
├─ skills/
├─ extensions/
├─ contexts/
│  └─ <conversationId>.json # 首次记录的 SDK 模型输入
├─ conversations/
│  └─ <conversationId>/
│     └─ conversation.json
└─ sessions/
   └─ <conversationId>.jsonl
```

### `teams/<conversationId>/`

多智能体任务记录使用每轮独立的 `<runId>.json`，保存执行者、任务版本/依赖/获准组合、全部执行尝试与代次、候选结果、验收状态、配置快照、邮箱、请求键去重记录和收到的用量；独立子会话位于 `<runId>/sessions/`，同一成员的接续任务复用自己的历史。共享任务在认领前没有 Agent/Attempt；认领和分配先保存归属再调度。每任务最多三次尝试，重试保留旧结果及原因，运行所有权和时限绑定到具体 Attempt/generation。

消息的来源身份由 Runtime 记录，queued/delivered/undelivered 分开；delivered 不代表已执行业务动作。这些记录含任务内容与实际工具配置，不应直接公开。删除主会话会一并清理；Runtime 重启将未结束的任务（包括未认领与阻塞项）标记 interrupted，未投递消息标记 undelivered，不自动重放通信、模型或工具操作。新增字段保留 schemaVersion=1，对旧记录缺省兼容；异常恢复不恢复执行权，跨根请求继续旧任务尚未实现。

### `contexts/<conversationId>.json`

`schemaVersion: 1`，当前 `policyVersion: tao-context-v2`；旧 v1 记录原样保留并兼容读取。主会话在首次实际调用模型前记录标准 SDK 输入，不记录供应商最终 HTTP 包。文件通过同目录临时文件、同步和原子替换保存；存在有效快照后不再覆盖。旧会话或保存失败后补记的 `conversationStart` 为 false，界面标明“首次记录”，不能充当原始启动记录。读取不依赖 Runtime 正在运行，读取失败显示错误；写入失败不阻止对话，下次请求重试。

保存系统指令、模型标识、组合 ID/名称/版本、环境和权限、来源、工具名称/说明/JSON Schema，以及消息角色/字符数。v2 增加可选 `contentSizes`，分别统计原始 system 与完整标准工具定义的字符数；展示裁剪不改变原始规模统计，字符数不代表 token 数。字段按白名单选择，不保存消息正文、隐藏推理、工具返回、请求选项、请求头或完整环境变量。常见凭据模式会遮盖；任意自定义文本中的密钥无法全部自动识别，仍应视为本地敏感数据。

系统指令最多 262144 字符、工具最多 100 个、参数结构最多 16384 字符、消息摘要最多 500 条；总记录按工具逐项裁剪至约 1.5 MB，读取硬上限 2 MiB。裁剪标记及原始计数随记录保存。删除主会话会删除此文件；不采集逐轮全量追踪，也不复制成员私有历史。

### `tao.json`

保存 Tao 产品设置和全局默认值，包括：

- 新会话默认 Provider；
- 新会话默认 Model；
- 默认思考模式；
- 权限确认超时时间；
- 主题；
- 强调色；
- Provider 档案和已保存模型。

### `auth.json`

保存 Pi 使用的 Provider API Key。它是敏感文件：

- 不进入 Git；
- 不进入发布资源；
- 不应复制到公开压缩包；
- 前端只读取“是否已配置”，不回显明文。

当前实现是 JSON 文件保存，不应把它误解为操作系统密钥库或加密保险箱。

### `settings.json`

保存 Pi 原生默认 Provider、Model 和默认思考模式，供 Pi Runtime 使用。

### `models.json`

保存 Tao Provider 档案转成的 Pi 兼容模型配置。它可以包含：

- 自定义 Provider；
- Base URL；
- API 协议；
- 多个模型及其上下文参数。

### `runtime/profile.json`

保存旧版 Tao 定制配置。首次读取时迁移到 `agents/catalog.json`，之后组合页以新目录为准，旧文件保留。旧配置包括：

- 系统提示词追加或替换；
- 会话附加提示词；
- 工具模式；
- 启用的内置工具；
- Skills/Extensions 开关；
- 自定义工具定义和权限模式。

### `agents/catalog.json`

当前格式版本为 `schemaVersion: 1`，包含：

- `revision`：目录版本，防止过期编辑覆盖新保存；
- `defaultProfileId`：新会话全局默认组合；
- `profiles`：组合名称、说明、版本、运行配置、自定义工具 ID 和可选默认模型；
- `tools`：共享工具库；
- `workspaceDefaults`：规范化工作区路径到组合 ID 的映射。

组合的 `configuration.customTools` 为空，实际工具定义只保存在工具库；创建会话时展开所选工具，形成独立快照。修改共享工具只增加引用组合的版本。

### `skills/`

Tao 产品级 Skills 目录。当前约定是：

```text
%USERPROFILE%\.tao\skills\<skill-name>\SKILL.md
```

不需要维护独立的 Pi 产品目录。

### `conversations/`

当前保存 Tao 产品投影和元数据：

- 标题；
- Provider、Model、思考模式；
- 权限模式；
- 工作区路径和显示名；
- 用户、助手和错误消息；
- 思考文本；
- 活动摘要；
- Trace；
- 附件引用。
- `agentSnapshot`：组合 ID、名称、版本和实际运行配置；
- 失败消息的 `retry.agentSnapshot`：原请求使用的配置。

已有会话不会自动跟随组合或工具库修改。首次打开没有快照的旧会话时补入当前默认快照；切换组合或“应用新版”只在会话空闲时执行。组合被删除后，已有会话仍可使用保存的快照。

新建组合使用开启委派的新默认值；JSON 反序列化缺少 `delegation` 时仍采用旧版关闭值，不迁移覆盖显式开关。开启且 `allowedProfileIds=[]` 表示本次请求解析一个继承配置的默认成员，其合成 ID 不写回组合库。已保存会话快照不会因此自动开启协作。

这是当前 UI 快速加载使用的过渡投影，不应该在这里重新实现 Pi 的上下文压缩或会话树。

### `sessions/`

保存 Pi Session JSONL。它是 Agent 上下文和 Pi 消息事实源。

删除会话时，Tao 会同时删除对应的 `conversation.json` 和 Pi session 文件。

## 3. 工作区和 `.tao` 的区别

工作区是 Agent 的真实 `cwd`：

```text
用户选择的项目目录
```

`.tao` 是 Tao 用户数据根目录：

```text
C:\Users\<用户名>\.tao
```

`.tao` 不是工作区，也不是沙盒。Agent 能否访问工作区外资源，取决于权限审计和后续安全设计，不是由 `.tao` 自动隔离。

## 4. 数据迁移

Tao 当前包含旧数据目录迁移逻辑。首次启动时可能会：

- 创建 `.tao`；
- 迁移旧 Tauri App Data；
- 迁移旧 Pi 配置和 session；
- 写入迁移标记；
- 保留旧目录作为备份或标记已迁移。

修改数据目录结构时，必须同步更新：

- `src-tauri/src/storage.rs`；
- 数据迁移标记；
- 本手册；
- 版本升级验证。

不能直接改路径而不提供旧版本数据处理方案。

## 5. 备份和清理建议

Tao 管理的 JSON 通过同目录临时文件写入、同步后替换。单个会话 JSON 损坏时，列表跳过该会话并显示警告，原文件保留；JSONL 对账失败时保留已有投影。此机制不代替定期备份。

组合导出包含所引用的工具，并移除项目默认映射；常见凭据字段会脱敏，`{{env:变量名}}` 引用保留。任意脚本和提示词中的文本无法全部自动识别为凭据，分享前应检查导出内容。工具定义及会话快照属于本地配置，推荐只保存凭据引用。

只备份源码，不需要复制 `.tao`。

要备份配置和会话，至少备份：

```text
%USERPROFILE%\.tao\tao.json
%USERPROFILE%\.tao\auth.json
%USERPROFILE%\.tao\models.json
%USERPROFILE%\.tao\settings.json
%USERPROFILE%\.tao\runtime\
%USERPROFILE%\.tao\agents\
%USERPROFILE%\.tao\conversations\
%USERPROFILE%\.tao\contexts\
%USERPROFILE%\.tao\teams\
%USERPROFILE%\.tao\sessions\
```

其中 `auth.json` 应单独保护。

释放开发机磁盘空间时，可以清理：

```text
src-tauri/target/
dist/
node_modules/
vendor/pi/node_modules/
.tao-release-cache/
```

不要为了释放项目空间删除 `.tao`，除非明确要删除 Tao 的用户配置和会话。
