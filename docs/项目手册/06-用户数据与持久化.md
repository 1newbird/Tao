# Tao 用户数据与持久化

## 1. Tao Home

Tao 的用户数据根目录是：

```text
C:\Users\<用户名>\.tao
```

代码通过 Tauri 的用户目录定位逻辑创建它。它与项目目录和 Agent 工作区分离。

## 2. 当前主要文件和目录

```text
.tao/
├─ tao.json
├─ auth.json
├─ settings.json
├─ models.json
├─ runtime/
│  └─ profile.json
├─ skills/
├─ extensions/
├─ conversations/
│  └─ <conversationId>/
│     └─ conversation.json
└─ sessions/
   └─ <conversationId>.jsonl
```

### `tao.json`

保存 Tao 产品设置和全局默认值，包括：

- 新会话默认 Provider；
- 新会话默认 Model；
- 默认思考模式；
- 权限确认超时时间；
- 主题；
- 强调色；
- Provider 档案和已保存模型。

### `auth.json`

保存 Pi 使用的 Provider API Key。它是敏感文件：

- 不进入 Git；
- 不进入发布资源；
- 不应复制到公开压缩包；
- 前端只读取“是否已配置”，不回显明文。

当前实现是 JSON 文件保存，不应把它误解为操作系统密钥库或加密保险箱。

### `settings.json`

保存 Pi 原生默认 Provider、Model 和默认思考模式，供 Pi Runtime 使用。

### `models.json`

保存 Tao Provider 档案转成的 Pi 兼容模型配置。它可以包含：

- 自定义 Provider；
- Base URL；
- API 协议；
- 多个模型及其上下文参数。

### `runtime/profile.json`

保存 Tao 定制 Agent 的第一版配置：

- 系统提示词追加或替换；
- 会话附加提示词；
- 工具模式；
- 启用的内置工具；
- Skills/Extensions 开关；
- 自定义工具定义和权限模式。

### `skills/`

Tao 产品级 Skills 目录。当前约定是：

```text
%USERPROFILE%\.tao\skills\<skill-name>\SKILL.md
```

不需要维护独立的 Pi 产品目录。

### `conversations/`

当前保存 Tao 产品投影和元数据：

- 标题；
- Provider、Model、思考模式；
- 权限模式；
- 工作区路径和显示名；
- 用户、助手和错误消息；
- 思考文本；
- 活动摘要；
- Trace；
- 附件引用。

这是当前 UI 快速加载使用的过渡投影，不应该在这里重新实现 Pi 的上下文压缩或会话树。

### `sessions/`

保存 Pi Session JSONL。它是 Agent 上下文和 Pi 消息事实源。

删除会话时，Tao 会同时删除对应的 `conversation.json` 和 Pi session 文件。

## 3. 工作区和 `.tao` 的区别

工作区是 Agent 的真实 `cwd`：

```text
用户选择的项目目录
```

`.tao` 是 Tao 用户数据根目录：

```text
C:\Users\<用户名>\.tao
```

`.tao` 不是工作区，也不是沙盒。Agent 能否访问工作区外资源，取决于权限审计和后续安全设计，不是由 `.tao` 自动隔离。

## 4. 数据迁移

Tao 当前包含旧数据目录迁移逻辑。首次启动时可能会：

- 创建 `.tao`；
- 迁移旧 Tauri App Data；
- 迁移旧 Pi 配置和 session；
- 写入迁移标记；
- 保留旧目录作为备份或标记已迁移。

修改数据目录结构时，必须同步更新：

- `src-tauri/src/storage.rs`；
- 数据迁移标记；
- 本手册；
- 版本升级验证。

不能直接改路径而不提供旧版本数据处理方案。

## 5. 备份和清理建议

只备份源码，不需要复制 `.tao`。

要备份配置和会话，至少备份：

```text
%USERPROFILE%\.tao\tao.json
%USERPROFILE%\.tao\auth.json
%USERPROFILE%\.tao\models.json
%USERPROFILE%\.tao\settings.json
%USERPROFILE%\.tao\runtime\
%USERPROFILE%\.tao\conversations\
%USERPROFILE%\.tao\sessions\
```

其中 `auth.json` 应单独保护。

释放开发机磁盘空间时，可以清理：

```text
src-tauri/target/
dist/
node_modules/
vendor/pi/node_modules/
.tao-release-cache/
```

不要为了释放项目空间删除 `.tao`，除非明确要删除 Tao 的用户配置和会话。
