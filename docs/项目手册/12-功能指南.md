# Tao 功能指南

本指南随当前应用源码一起打包。已有 MSI 的功能以对应版本为准；开发中的功能完成代码后仍需桌面与安装验收。

## 快速开始

1. 在“设置 → 模型与 Provider”填写服务地址、模型和认证，保存并测试连接。
2. 在主界面新建对话，选择工作区、模型和智能体组合。
3. 输入任务开始对话；读取文件、运行命令和修改文件按照当前权限规则执行。
4. 生成时可以向上查看历史，点击“回到最新”恢复跟随。右侧“工作过程”展示执行状态，“文件”预览工作区内容，“上下文”查看首次模型输入的记录。

开发者从源码启动时使用项目的环境准备脚本和 `npm.cmd run tauri dev`，详见项目部署手册。普通用户使用安装包，无需安装 Node.js 或 Rust；命令工具依赖的外部程序仍需可用。

用户问题和助手回答都提供“复制”按钮，悬停消息或键盘聚焦后可见。复制问题后可新建会话，再粘贴到输入框复用问题；保留原文及换行。

## 任务状态与恢复

发送消息后，Tao 先保存用户消息和任务记录，再启动后台执行。发送回执不等于执行完成；消息区持续显示输出，结果保存成功后才结束本轮。不同会话可以并发，同一会话有任务或待保存结果时不能再执行一轮。

- **回执或通知丢失**：使用原任务编号核对，页面可见时定期查询，回到窗口时再次查询。启动回执丢失只重试同一编号的提交，不会重新创建任务。
- **停止**：只停止所选任务，旧任务的停止和追加请求不会影响下一轮。显示“正在停止”时仍在等待执行结束；未收到结束记录时可以重试停止，必要时在 Runtime 设置中重启后台。
- **结果待保存**：执行已结束，点击“重试保存”只保存已有结果，不再调用模型或工具。保存成功前不能开始下一轮。未保存结果暂存于当前应用内存，应先恢复保存再退出。
- **后台断开或应用重启**：未完成记录标为中断，不自动重放任务。已有文件和外部系统操作不会回滚，应先核对实际结果，再决定是否重新执行。
- **状态暂不可查询**：界面显示核对失败，不将连接异常当成执行失败，也不自动再执行任务。恢复连接后继续核对。

生成或结果待保存期间，工作区、模型和组合保持固定。重试失败消息会使用该次任务保存的配置；如果之后已经有新的对话消息，应在当前会话明确发起新任务。

## 智能体组合

组合保存系统提示词、会话附加要求、工具选择、默认模型、Skill 开关与权限规则。在“定制 → 组合设置”新建、复制、保存或导入组合，然后在会话中选择。

- 会话使用配置快照。修改组合不会悄悄改变正在运行的任务。
- 项目可以设置默认组合，新对话会采用该默认值。
- 自定义工具在工具库定义，再加入需要的组合。工具可以调用命令或 HTTP 接口，参数须符合其输入 Schema。
- 新建组合默认开启子代理协作，可设置并发、任务数、执行时长和模型轮次上限。未指定子组合时使用继承当前组合的“默认成员”；指定组合后仅可委派给所选组合。协作工具自动注册，无需在普通工具页勾选，也可明确关闭委派。已有组合和会话保留原开关，旧数据缺少委派配置时保持关闭。

组合描述任务要求，工具权限决定能执行什么。提示词不能扩大授权范围。

## 工具与权限

工具支持继承默认审核、询问确认、自动允许和禁止执行。文件工具可以限制为当前工作区。自定义命令和 HTTP 工具会真实执行，请在工具定义中填写所需程序、地址与输入参数。

子代理继承父任务与自身组合允许能力的交集；任何一方禁止的工具都不能由子代理放开。权限确认会标记实际子任务，用户在主会话处理确认或拒绝。

“定制 → 执行与沙盒”可选择本机或 Docker，并设置文件、网络和凭据范围。Docker 工具后端只挂载当前项目，默认断网，失败不回退本机；需要已安装 Docker 和准备镜像。普通本机模式没有操作系统隔离。多个成员仍共用工作区，任务分工应明确写入范围。完整操作见 [权限、沙盒与压缩策略](./13-权限执行沙盒与压缩策略.md)。

Docker 是可选依赖。安装并启动其 Linux 容器后端后，可在 PowerShell 执行 `docker pull node:22-bookworm-slim`，然后选择组合的 Docker 后端、点击“检测沙盒环境”、保存并在新会话中选择具体项目目录。已有会话需空闲后明确应用新版组合。只读、断网和显式禁止不受“完全放行”覆盖。

## 多智能体协作

在主组合中启用“子代理协作”后，主代理可以派发成员。成员有独立上下文，可以与同树成员通信，查看并认领共享任务。任务依赖必须通过 `dependsOn` 显式填写；前置任务经过验收后，下游才能执行。仅在首次调用协作工具时建立本轮记录，普通问答不会产生空团队。默认成员继承当前工具与配置，仍受父子权限交集限制，不会递归派发。

### 查看成员

展开右侧“工作过程”，在可折叠的“协作成员”区域选择轮次和成员；中间区域随之显示该成员的对话、工具执行摘要、协作消息及任务历史。点击“返回主对话”或右侧“主对话”回到原聊天，保留阅读位置；主对话顶部不常驻成员栏。收起右侧面板不关闭正在查看的详情。

点击详情中的“独立窗口”可在新窗口查看同一个成员。打开查看页不创建新的执行者，返回主对话或关闭查看窗口不停止任务。退出 Tao 会关闭后台运行。

对话展示可见的模型输出。执行记录只展示工具名称与状态，不展示隐藏推理、原始工具参数和完整返回内容。旧记录可能只有最终结果；较长记录存在保存或显示上限，界面会提示。

### 人工介入

- **补充当前任务**：说明先入箱，在下一次模型调用前送达。成员当前的模型请求或工具调用不会被强行打断。目标执行尝试结束后，未送达说明不会转交下一任务。
- **追加新任务**：填写名称和要求，新建任务并复用该成员的历史；成员忙时排队，单成员按顺序执行。
- **停止当前任务**：取消选中的执行任务，其他排队任务可以继续。
- **停止成员及排队任务**：停止该成员，保留其他成员。
- **停止整轮协作**：停止主请求及其所属子任务。

人工操作尽量在主代理邮箱记录通知；通知容量耗尽时，停止仍然执行，以任务状态和操作回执为准。文字不会修改工具权限。消息“已进入上下文或工具结果”只证明已投递，不表示对方已经处理或完成工作。

草稿绑定编辑时的任务和执行尝试。任务或版本切换后，发送会暂停，需要用户明确确认新的目标。成员切换会保留该成员草稿和阅读位置；未发送草稿不自动落盘。

### 生命周期与结果

运行结束先“已提交”，主代理根据证据验收为“已验收”或“未通过”。重试保留原任务及旧执行尝试；已发生的文件或外部操作不会回滚。

当前支持一层父子关系、单机单 Runtime。主代理本轮结束会回收未完成成员；之后查看页只读，继续工作需从主会话发起新任务。Runtime 重启后未完成任务标为“已中断”，不会自动重放工具操作。令牌和费用硬预算、跨轮常驻成员、递归团队尚未实现。

## 工作说明与流式阅读

模型在工具调用前给出的简短说明会归入“工作过程”，支持 Markdown；最终回答保留在正文。支持阶段信息的 Responses 模型可以边生成边归类；没有阶段信息的接口需等该条助手消息结束，再根据是否调用工具归类。界面不会自行编造计划，也不会把隐藏推理当作工作说明。

生成中可以手动展开或折叠工作过程，该选择在本轮结束时保留。上翻后不强制返回底部，点击“回到最新”恢复跟随。工作过程跟随主消息区域滚动，避免嵌套滚动导致底部内容不可达。

## 提示词与上下文

### 配置预览

在“定制 → 系统提示词”点击“查看预览”，选择“组成与来源”“默认提示词”或“合成预览”。修改草稿会使旧预览失效，需要重新预览。

- 当前策略为 `tao-context-v2`。Tao 是通用任务助手，根据组合与用户目标调整领域角色。组成依次包含角色、实际工具短索引与指导、平台执行规则、工作说明、按角色加载的协作规则、按需文档入口、自定义追加/会话要求、启用资源和运行环境。执行规则包含范围遵守、证据验证、失败与副作用处理、持续推进及结果如实报告。
- “默认提示词”展示当前工具/协作设置下的完整默认模板，包含平台规则与动态占位符，不含业务自定义文本；“合成预览”显示当前草稿的追加或替换结果。
- 替换只替换身份与角色，保留实际工具指导、平台规则、会话附加要求和环境权限；空白替换使用默认角色。关闭自定义提示词也不会关闭平台规则或修改工具授权。
- 路径、权限、系统、时间等使用占位符。模板不会创建 Session、调用模型或执行扩展，也不读取 `SYSTEM.md` 和 Skills 正文。实际运行时这些资源可能覆盖或追加内容。

### 会话记录

展开右侧面板并选择“上下文”。首次实际调用模型前，Tao 保存该次 SDK 输入的系统指令、工具名称/说明/参数结构、消息角色与大小、组合版本、模型、环境和权限。工具与消息分开列出，不会把工具定义误当成系统提示词正文。

记录保存到本地，已有记录不随后续权限、模型或组合变化而覆盖。界面提示当前配置与首次记录的差异；每轮实际请求仍使用当时有效的权限。旧会话补记或保存失败后重试得到的记录标为“首次记录”，不能还原原始启动上下文。保存失败不阻止对话，界面显示警告，下一次请求重试。

这只是 SDK 输入快照，供应商适配器或扩展仍可能转换最终 HTTP 请求。快照不保存用户/助手消息正文、工具返回、隐藏推理、认证选项、请求头或完整环境变量；系统提示词和工具描述使用常见凭据遮盖规则。自定义文本无法保证完全自动脱敏，请勿把密钥写入提示词，分享记录前仍需检查。过长内容会裁剪并提示。

`systemPrompt`、`messages` 和 `tools` 是独立字段；页面分别展示，未合并成一段 system 消息。system 只含实际工具名称和短用途；自定义工具摘要使用有长度上限的标签，协作工具使用固定短用途。完整说明与参数结构仅通过 `tools` 传递，也会占用上下文。页面分别显示 system 和完整工具定义的字符数，字符数不等于 token 数，不能直接当作费用。

内置 `read_tao_doc` 不需要在工具库创建或普通工具页勾选。它只按 `tools`、`collaboration`、`permissions`、`customization` 四个专题读取随包运行手册，不读取用户文件或联网；正文按需进入工具结果，默认不预载全部文档。此工具仍遵守显式工具权限，不能借查阅文档扩大能力。

旧快照如实保留当时的输入与策略版本，不自动重写。源码开发时需重启 Runtime，并新建会话或查看新的首次记录验证修复；旧 v1 快照没有大小字段时仍可查看。真实模型验收步骤见项目手册的“常见问题与验证清单”。

当前仅主会话记录一次，按需读取；没有逐轮完整请求追踪或独立的子代理上下文快照页。

### 压缩策略与后续能力

主会话与每个成员分别维护上下文，成员默认接收委派任务和明确提供的信息。普通通信不自动复制完整会话历史。

“定制 → 上下文策略”可设置继承、自定义自动压缩或关闭，配置预留空间、近期保留与摘要要求；主会话和成员分别使用其快照。摘要使用当前模型并产生用量，实际过程及结果写入会话记录。外部记忆、独立摘要页、团队级硬预算和成员文件隔离仍待开发；详见 [压缩策略](./13-权限执行沙盒与压缩策略.md#压缩策略)。

## 数据与排错

默认用户数据位于 `%USERPROFILE%\.tao`。组合、普通会话、上下文快照、协作轮次与成员私有历史分别保存。删除主会话会删除其所属上下文和协作记录。

- 后台连接失败：在“设置 → Runtime”查看真实状态和错误，再重试启动。
- 成员等待确认：返回主会话处理该任务的权限请求。
- 成员查看页断线：控制操作暂停，刷新后核对状态；错误时保留输入，避免盲目重复追加任务。
- 任务已结束：历史记录只读，请通过主会话发起新任务。
- 停止或重启：不撤销已有文件或外部系统修改；重试之前先核对实际状态。

诊断问题时记录所属主会话、协作轮次、成员和任务标识。不要分享认证文件或 API Key。
