# Tao 项目现状与功能清单

最后核对：2026-10-26，对应 0.3.0。标记为“已实现”的功能表示代码中有完整产品路径，不表示每项异常路径均已专项验收；“已接入但有限制”需遵守范围说明。发布与验证依据见 [0.3.0 验收记录](../验证/2026-10-26-0.3.0发布验收.md)，当前待办统一见 [开发 TODO](../开发TODO.md)。

## 产品壳层

0.3.0 增量：联网检索与 MCP 拆为独立配置页，Skills 默认展示技能库并按需展开添加入口；聊天“能力”读取会话生效快照，区分搜索服务、网页读取及配置限制。新增 `tao-runtime:0.1.0` 基础镜像配方和手动准备入口，覆盖 Node/Python/Git 与常用工具，安装版使用随包配方本机构建。镜像托管、搜索服务部署和全局 MCP 连接库尚未实现。

## 权限与执行安全

| 功能 | 状态 | 当前说明 |
|---|---|---|
| 会话权限模式 | 已实现 | `询问确认` 或 `完全放行` |
| 工具调用前审计 | 已实现 | Runtime 通过 Pi Hook 判断工具、路径、命令和范围 |
| 权限弹窗 | 已实现 | 可允许一次、允许本会话或拒绝 |
| 权限超时 | 已实现 | 设置范围为 5 到 600 秒，超时自动拒绝 |
| 自定义工具单独权限 | 已实现 | 自定义工具可以独立设置权限模式 |
| 组合工具权限 | 已实现 | 继承、询问、允许、禁止；显式禁止和工作区限制优先于完全放行；工具库询问上限不能被组合放宽 |
| 文件工具工作区范围 | 已实现 | 解析最近存在父目录的真实路径，阻止目录链接指向工作区外的新文件；仍不属于沙盒 |
| 统一工具执行接口 | 已实现 | 内置命令、自定义程序/命令及对应文件工具使用统一执行边界；本机命令不能强制的限制会被拒绝 |
| Docker 工具沙盒 | 已接入但有限制 | Linux 容器执行，工作区挂载、只读、断网、环境名单、资源和超时限制；需另备 Docker/镜像，失败不回退本机 |
| Windows 原生工具沙盒 | 已接入，预览 | AppContainer + Job Object、文件 worker、管理员检测/初始化/移除、租约及 ACL 恢复；随包兼容 Node/npm。命令使用 PowerShell、始终断网、单次最多 120 秒；Windows 10 等专项待验收，详见执行策略手册 |

权限确认解决的是“是否允许这次动作”，沙盒解决的是“即使程序被允许，它最多能碰到什么资源”。两者不是同一个能力。

| 功能 | 状态 | 当前说明 |
|---|---|---|
| 工作区目录浏览 | 已实现 | 只允许工作区内相对路径，跳过 `.git` |

| 附件上传到模型服务 | 未实现 | Tao 传递的是本地文件引用，模型需要通过工具读取 |
| Markdown 导出 | 已实现 | 导出已保存的会话消息 |
| JSON 导出 | 已实现 | 导出结构化会话数据 |
| 纯文本导出 | 已实现 | 不包含 UI 控件和原始工具结果 |

## 已知未完成项

**待设计或实现：**团队总 token/费用/时长预算；摘要浏览与按需逐轮追踪；产品级上下文生命周期、Extension/Hook 和插件/工作流管理；协作更深恢复与共享文件冲突处理；非 Git 改动追踪、附件增强、脱敏诊断、签名及其他平台发布。跨轮常驻成员和递归团队需单独决策。

**已有实现、仍待专项验证：**原生多窗口及任务中断的桌面异常路径、Docker 服务中断、真实长对话压缩、UAC 点击取消、明确卸载/实际升级、重启、Windows 10、跨用户与长期压力，以及无 Node/源码的干净电脑安装。不能把这些统一写成“尚未开发”。

0.3.0 已完成开发机自动回归、实际 MSI 提取/逐文件校验及 GitHub 发布，详见[本版验收](../验证/2026-10-26-0.3.0发布验收.md)。自动 SDK 使用本地模拟网关；实际用户覆盖安装仍待验收。0.2.0 曾通过用户整体安装试用和另行真实模型测试，其结论不代替新版或逐项异常验收。历史批次“未打包/等待发布”的记录保留当时含义，见 [TODO 归档](../开发TODO-历史记录-截至2026-10-21.md)。
