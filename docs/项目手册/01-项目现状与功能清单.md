# Tao 项目现状与功能清单

本清单按当前代码审查结果整理。标记为“已实现”的功能，表示当前代码中有完整产品路径；标记为“已接入但有限制”的功能，需要遵守后面的范围说明。

| Tauri + React + TypeScript 桌面应用 | 已实现 | 主界面由 React 构建，Rust 提供桌面和文件边界 |
| 左侧会话栏 | 已实现 | 新建、切换、搜索、置顶、重命名、删除 |
| 中央对话区 | 已实现 | 用户消息在右侧，助手回答在左侧 |
| 右侧检查器 | 已实现 | 工作过程、Runtime 信息和文件视图 |
| 左右侧栏收起与拖拽 | 已实现 | 侧栏宽度和文件目录宽度可调整，布局保存到前端 localStorage |
| 主题 | 已实现 | 浅色、深色、跟随系统 |
| 强调色 | 已实现 | Tao、开发者绿、蓝青、琥珀、石墨 |
| 快捷键 | 已实现 | 新建、搜索、侧栏、停止等基础快捷键 |

## 权限与执行安全

| 功能 | 状态 | 当前说明 |
|---|---|---|
| 会话权限模式 | 已实现 | `询问确认` 或 `完全放行` |
| 工具调用前审计 | 已实现 | Runtime 通过 Pi Hook 判断工具、路径、命令和范围 |
| 权限弹窗 | 已实现 | 可允许一次、允许本会话或拒绝 |
| 权限超时 | 已实现 | 设置范围为 5 到 600 秒，超时自动拒绝 |
| 自定义工具单独权限 | 已实现 | 自定义工具可以独立设置权限模式 |
| 组合工具权限 | 已实现 | 继承、询问、允许、禁止；显式禁止和工作区限制优先于完全放行；工具库询问上限不能被组合放宽 |
| 文件工具工作区范围 | 已实现 | 解析最近存在父目录的真实路径，阻止目录链接指向工作区外的新文件；仍不属于沙盒 |
| 操作系统沙盒 | 未实现 | 当前没有 Docker、VM、Gondolin 或 Windows 隔离后端 |

权限确认解决的是“是否允许这次动作”，沙盒解决的是“即使程序被允许，它最多能碰到什么资源”。两者不是同一个能力。

## 文件、附件、Diff 和导出

| 功能 | 状态 | 当前说明 |
|---|---|---|
| 工作区目录浏览 | 已实现 | 只允许工作区内相对路径，跳过 `.git` |
| Markdown/MDX 预览 | 已实现 | 支持预览/源码，单文件预览上限 2 MB |
| Git 改动列表 | 已实现 | Git 工作区读取 `git status --short` |
| Git 文本 Diff | 已实现 | 支持 staged 和 unstaged Diff 的摘要展示 |
| 非 Git 改动追踪 | 未实现 | 当前只能浏览文件，不能从工具事件恢复完整变更历史 |
| 消息文件附件 | 已实现 | 最多 8 个，单文件最多 20 MB，支持文本和代码类型 |
| 附件上传到模型服务 | 未实现 | Tao 传递的是本地文件引用，模型需要通过工具读取 |
| Markdown 导出 | 已实现 | 导出已保存的会话消息 |
| JSON 导出 | 已实现 | 导出结构化会话数据 |
| 纯文本导出 | 已实现 | 不包含 UI 控件和原始工具结果 |

## 已知未完成项

当前最重要的未完成项：

1. 完整事件驱动的任务生命周期，替代长时间阻塞的 `send_message` 外层 RPC；
2. 干净 Windows x64 电脑上的 MSI 安装和全链路对话验收；
3. NSIS 资源压缩和安装包体积优化；
4. 多智能体协作、上下文策略及 Extension/Hook 编辑；
5. 真正的沙盒执行；
6. 非 Git 工作区改动追踪；
7. 应用关闭后的生成恢复流程；
8. 代码签名和其他平台发布。

2026-10-13 开发批次已通过类型检查、前端构建、Rust 测试和本地模拟 Runtime 回归。桌面交互验收与新 MSI 安装验收仍需另行完成；已发布的 v0.1.3 不包含本批源码改动。操作说明见 [智能体组合与工具使用](./10-智能体组合与工具使用.md)。
