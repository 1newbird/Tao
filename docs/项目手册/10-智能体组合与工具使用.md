# Tao 智能体组合与工具使用

本说明对应 0.3.0，最后核对于 2026-10-26。功能实现、自动回归和桌面专项验收分别记录，发布状态见 [0.3.0 验收](../验证/2026-10-26-0.3.0发布验收.md)，当前待办见 [开发 TODO](../开发TODO.md)。

## 1. 创建组合

1. 打开“定制”，在左侧组合标题旁点击“+”新建；右上角“组合操作”菜单可复制、删除或导出组合。
2. 填写名称和说明，设置系统提示词追加/替换、会话附加提示词。
3. 在工具页选择内置工具，以及工具库中要启用的工具。
4. 设置工具权限；按需开启 Tao Skills，选择默认模型和思考模式。
5. 在底部点击“保存组合”。“测试组合”会保存并创建独立测试会话，发送消息后验证效果。保存同时包含组合配置与共享工具库。

工具库由所有组合共享，启用选择按组合独立保存。在工具页点击工具标题展开定义和测试，新建工具会自动展开。修改共享工具会增加所有引用组合的版本；已有会话保留旧定义。工具删除前需要取消其他组合对它的引用。

“系统提示词”页底部提供上下文预览，可查看完整默认模板、组成来源与草稿合成结果。替换模式仅替换身份与角色，实际工具指导、平台执行规则、工作说明、附加要求和运行环境保留；空白替换使用默认角色。预览中的路径/权限未绑定，实际首次输入在会话右侧“上下文”中查看。工具完整定义单独展示，字符数不等于 token 数。详见[功能指南](./12-功能指南.md)。

0.3.0 的 Skills 入口提供清单、导入、按组合选择、显式调用及 GitHub 安装，见下文。多智能体的当前范围见下文；组合级压缩策略及 Docker/Windows 原生预览已接入，见 [执行与上下文策略](./13-权限执行沙盒与压缩策略.md)。Extension/Hook 的完整产品配置仍待后续开发。

### Skills 管理与调用（当前源码）

1. 打开“定制 → 技能 · Skills → 添加技能”，点击“导入本地目录”，选择根目录含 `SKILL.md` 的单个技能。说明使用 YAML frontmatter，至少填写 `name`（小写字母/数字/单连字符，最多 64 字符）及 `description`（非空，最多 1024 字符）。
2. 导入会立即复制说明和附属文件到 `%USERPROFILE%\.tao\skills/<name>`，由所有组合共享；不覆盖同名技能/已有目录，不执行代码，跳过 `.git` 和 `node_modules`。拒绝符号链接/目录联接；最多 2000 项、8 层，说明 128 KiB，其他单文件 4 MiB，总计 32 MiB。
3. 启用 Skills 后选择“全部已安装技能”或“仅选中的技能”，再保存组合。旧配置缺少 `enabledSkills` 或值为 null 时仍加载全部；空数组表示一个也不选。子代理选择取父子交集。
4. 新会话输入框显示“使用技能”，选中后插入 `/skill:名称 你的任务`，保留已有文字。命令位于消息开头、名称后用空格分隔，复用内核载入说明正文；不依赖 read 工具。设置 `disable-model-invocation: true` 的技能只供显式调用。
5. 自动匹配依赖 read 工具及技能元数据；读取附属文件和执行脚本仍受组合权限/工作区/沙盒限制。导入不是授予任意路径访问或代码执行权。当前尚未提供沙盒资源同步、在线技能市场及自动升级。

清单会显示缺失描述、名称冲突、超大文件和目录链接等加载问题。正常的技能解析及命令展开复用内核；目录发现增加边界检查。已加载会话保持其技能列表，选择器反映该列表；新导入技能请新建会话使用。组合快照保存开关和选择名单，不冻结技能文件内容，外部修改文件仍可能影响后续读取。

### 从 GitHub 安装技能（2026-10-23 当前源码）

“定制 → 技能 · Skills → 添加技能 → 从 GitHub 安装技能”支持公开 GitHub 仓库、`tree` 目录和 `SKILL.md` 文件链接。点击“检查技能”，仓库含多个技能时选择具体目录；核对名称、说明、固定提交、文件清单、安装位置及依赖提示后点击安装。分支名含斜杠时填写仓库根地址，并展开可选项分别填写 ref 与目录。无需 Git、Python 或已部署的搜索服务。安装立即保存到共享技能库；组合启用和选择另行保存。

对话安装需开启独立的“允许对话安装技能”，保存组合后新建会话，再发送“帮我安装这个技能：GitHub 链接”。主会话获得 `list_installed_skills`、`inspect_github_skill`、`install_github_skill`；可按需读取 `read_tao_doc(topic: "skill_install")`。检查固定提交，安装使用本会话 10 分钟内的预览，每次确认显示来源/提交/目标；完全访问模式或工具 allow 仍需确认，明确 deny 仍阻止安装。子代理不提供安装能力，旧配置默认关闭。

安装复用本地导入限制，另拒绝子模块、Git LFS、危险文件名和不完整清单；逐个验证 Git blob SHA，记录 `.tao-source.json`。同名目录不会覆盖；失败清理临时下载。来源校验只证明内容与提交一致，不保证安全或兼容。只提示 scripts/、Codex `agents/openai.yaml` 等依赖，不执行代码、不安装程序/MCP、不修改组合。安装后在组合中启用/选择技能、保存并新建会话，已加载会话不会热加载。

这是写入固定共享 Skills 目录的应用管理操作，不扩大文件/命令工具权限；后续使用仍可能受工作区和沙盒限制。访问 `api.github.com` 与 `raw.githubusercontent.com`，沿用组合联网、域名名单和工具禁止规则，不读取 GitHub 凭据，拒绝重定向和私网。403/429 可能限流；404/401 表示不存在或不可公开访问。当前不支持私有仓库、GitLab/Gitee、自动更新或 MCP 服务安装。

### 联网搜索与网页读取（当前源码）

在“定制 → 联网检索”分别开启两项能力，默认关闭；它们独立于 Coding Agent/自定义工具模式。页面区分关闭、配置缺失、凭据或网络受限、已配置待测试，以及本次测试结果；配置检查不联网、不返回密钥值。网页读取无需搜索服务，模型 API 配置也不会自动提供搜索能力。保存后新会话采用配置，已有会话需应用新版组合；聊天顶部“能力”依据会话生效快照展示，不采用未保存草稿。

- **web_search**：按组合选择 Brave Search 或 SearXNG，统一返回标题、URL、摘要、抓取时间及服务实际提供的页面时间，最多 1–10 条。Brave 支持日/周/月/年筛选；SearXNG 支持日/月/年，效果取决于上游引擎。搜索服务及费用由用户管理。[Brave 接口](https://api-dashboard.search.brave.com/app/documentation/web-search/codes)、[SearXNG 接口](https://docs.searxng.org/dev/search_api.html)。
- **web_fetch**：直接读取公开 HTML、纯文本与 Markdown，无需搜索密钥；返回最终 URL、标题、静态正文、部分页面链接、抓取时间及下一段位置。默认正文 12,000 字符，每段最多 20,000 字符；按 nextOffset 继续会重新请求，因此页面变化可能影响分段。
- Brave 密钥默认从 `BRAVE_SEARCH_API_KEY` 环境变量读取。系统中设置其值后重启 Tao，并在“执行与沙盒 → 工具凭据”授权这个变量名称。配置只保存变量名，不保存密钥，也不自动放宽凭据名单。SearXNG 不使用 Brave 凭据。
- 联网开关、域名名单及工具权限共同生效。若设置域名名单，需要包含所选搜索服务主机（Brave 为 `api.search.brave.com`）和要读取的网站；名单约束 Tao 的请求目的地，不能约束 SearXNG 服务端访问的上游。搜索返回的链接不代表都可以读取。对话调用默认请求确认，也可按工具设为允许/禁止。
- 本机、Docker 和 Windows 原生组合的联网工具均由 Runtime 发起受控 HTTP 请求；Windows 原生命令仍离线。子代理只能使用父子共同启用的能力及权限，搜索来源须一致；Brave 凭据变量须一致并在交集名单中，SearXNG 接口地址须一致，私网开关取交集。
- 单次总请求超时 30 秒，取消终止请求；普通网页最多跟随 5 次重定向，每跳重查域名与公开 IP，只访问标准 HTTP/HTTPS 端口，不访问本机/内网。响应及解压后正文均限 2 MB。两种搜索接口都不跟随重定向。
- 当前为静态正文提取，可能保留页面杂项或遗漏复杂布局；不执行网页脚本，不读取登录态，不支持 PDF、二进制下载或浏览器交互。不能把抓取成功等同于来源可信，也不能把摘要视为已核对正文。回答通过现有 Markdown 链接引用来源。
- 已有同名自定义 `web_search` / `web_fetch` 可在内置联网关闭时继续使用；开启相应内置能力前需先重命名自定义工具。

建议验收：搜索某个主题 → 读取来源正文 → 带可点击来源回答。缺少密钥、禁止联网或网页不可读时必须明确失败。真实 Brave 凭据和桌面安装专项验收另行记录，不能用离线模拟代替。

**SearXNG 配置步骤：**

1. 在联网设置中选择 SearXNG，填写完整接口地址，例如 `http://127.0.0.1:8080/search` 或 `https://search.example.com/subpath/search`。支持自定义端口；不附带查询参数、片段或登录凭据。Tao 发送 GET 请求，自动追加 q、format=json、categories=general 和可选 time_range。
2. 实例必须在 `settings.yml` 的 `search.formats` 中启用 `json`；否则可能返回 403。当前不支持认证请求头、登录 Cookie、证书校验绕过或自动部署。只连接已有实例。
3. 若使用本机/私网实例，开启“允许此搜索接口访问本机或私网”。它只对精确配置的接口生效，支持回环、RFC1918 IPv4 和 IPv6 ULA；链路本地、云元数据、未指定、多播及 IPv4 映射 IPv6 等地址仍拒绝。DNS 解析后固定地址连接；普通 web_fetch 不受此开关影响。
4. 点击“测试搜索连接”。这明确触发一次使用当前草稿的固定查询 `SearXNG documentation`，不读取会话内容；测试仍遵循禁止联网、域名名单和工具禁止规则，30 秒超时。成功仅代表接口连接和返回格式有效，不代表所有上游正常或结果质量已验收。更改配置后旧测试状态会清除，再保存组合。

JSON 无效、HTTP 403/429、重定向、无法连接及上游失败均明确反馈。有结果但部分引擎失败时返回 warnings；没有结果且有引擎失败时返回错误，不伪装成普通空结果。源码已通过本机模拟 HTTP 服务与模拟模型调用；目前没有用户提供的实际 SearXNG 实例，尚未验收真实检索质量或安装包。

[SearXNG](https://github.com/searxng/searxng) 聚合上游引擎，开源不等于拥有独立全网索引或免维护，公共实例不作为默认依赖。复杂页面读取仍可评估 [Crawl4AI](https://github.com/unclecode/crawl4ai)，尚未接入。搜索服务提供入口，最终证据仍来自返回的网站正文，保留原始来源链接和时间。

### MCP 外部工具（2026-10-22 当前源码）

“定制 → 外部服务 · MCP”可添加最多 20 个已有的 Streamable HTTP 服务。服务摘要区分启用、当前页面的连接测试和已选工具数量；展开“管理连接与工具”填写完整接口地址（通常为 `/mcp`），点击“测试连接并查看工具”，再勾选允许对话使用的工具并保存组合。未勾选的远程工具不能调用；修改地址或凭据变量会清空选择，需重新检查服务。新会话使用当前配置，已有会话沿用组合快照，明确应用新版后才更新。服务仍按组合配置，未引入全局连接库。

可选 Bearer 认证只保存环境变量名称，其值需在系统环境中设置并重启 Tao，同时加入“执行与沙盒 → 工具凭据”允许名单；远程认证要求 HTTPS，本机回环可用 HTTP。不支持明文配置凭据、URL 查询参数、任意请求头或重定向。本机/私网接口需单独勾选，特殊地址始终禁止；DNS 解析结果经校验后固定到本次连接。

连接测试只执行初始化和工具清单读取，不执行远程工具或发送会话内容，但会将配置的认证发送给此服务。对话提供 `mcp_list_tools`（返回已授权工具及输入 Schema）和 `mcp_call_tool`（调用指定工具）。工具调用默认询问，确认框展示服务、接口、工具与脱敏参数摘要；可在工具权限中设置询问/允许/禁止。完全放行仍受显式禁止、联网、域名、凭据和工具名单限制。服务端 annotations 不自动授予权限。父子服务 ID、接口、凭据变量须一致，工具和私网授权取交集。

实现边界：支持协议 2025-03-26 / 2025-06-18 / 2025-11-25，JSON 和 POST SSE、分页、工具输入 Schema 校验、文本/结构化返回与 isError。每次发现或调用创建独立短连接会话，结束时尽力 DELETE 清理，不保存跨调用服务端状态；30 秒总超时，最多 100 个工具/20 页、单次响应 2 MB，结果显示有长度上限。取消尽力通知服务端，不自动重试有副作用的调用；取消、失败或会话清理不代表远程操作已回滚。

不支持 stdio、旧版 HTTP+SSE、OAuth、Resources/Prompts、服务端请求（包括 sampling/elicitation/ping）、GET 通知订阅、断线恢复和多模态结果展示。服务描述和返回只作为外部资料，不注入系统指令。远程服务行为无法受 Tao 本地文件沙盒约束；域名名单仅限制连接目的地。客户端随包分发，无新增依赖，不自动安装服务；用户仍需自己的服务地址和必要凭据。

搜索服务部署已按用户决定暂缓，后续需提供其他安装用户可访问的服务或托管方案；现阶段支持搜索接入不等于安装后无需配置即可搜索。MCP 的基础接入不依赖搜索服务部署。

协议依据：[传输](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[生命周期](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)、[工具](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。

## 2. 会话与项目

- 新会话先使用项目默认组合，项目没有默认时使用全局默认。
- 点击对话顶部的组合名称，在菜单中切换当前会话组合；运行中和准备中禁止切换。
- 保存组合后，已有会话仍使用原版本。在组合菜单中点击“应用新版组合”明确更新该会话。
- 切换组合保留已有消息和上下文；需要完全独立的上下文时新建会话。
- 在对话顶部的组合菜单中把当前组合设为项目默认，之后新建会话使用该组合的最新版本。可以恢复使用全局默认。
- 删除组合后已有会话保留快照；失败重试保留原请求的配置。

组合保存后不重启整个 Runtime。配置页在左侧切换组合会保留未保存草稿；右上角组合操作菜单中的“重新读取”丢弃草稿，读取磁盘上的当前配置。遇到过期配置保存错误时，可先导出草稿再重新读取。

## 3. 工具定义

每个工具需要稳定 ID、模型调用名称、说明、输入 JSON Schema、权限模式和超时时间。工具名称不能与内置工具重名。输入在模型调用和手动测试时都进行校验；自定义工具超时范围为 1–120 秒，输出读取上限为 2 MB，返回文本最多 20,000 字符。

### 程序与参数

新工具默认使用程序类型。可执行文件和参数分开传递，参数不经过 Shell 拼接。`node`/`node.exe` 使用 Tao 当前内置 Node；其他程序需要安装在目标电脑上。

例如：

```text
程序：node
参数：["-e", "process.stdout.write(process.argv[1])", "{{text}}"]
```

对应输入 Schema：

```json
{
  "type": "object",
  "properties": { "text": { "type": "string" } },
  "required": ["text"],
  "additionalProperties": false
}
```

`{{字段名}}` 代表相应输入值；`{{input}}` 代表整个输入对象的 JSON。程序也可读取环境变量 `TAO_TOOL_INPUT_JSON`。复杂参数可以完全通过这一个变量读取，避免模板拼接。

### Shell

保留命令模板工具以兼容旧配置。Shell 会解释替换后的命令文本，适合受控的本地脚本；对模型输入应优先使用程序与独立参数。超时和取消会终止所启动的进程树，已完成的写入不会回滚。它尚未提供 OS 隔离。

### HTTP

支持方法、URL、请求头和请求体模板。可填写允许的完整主机名，不含协议、端口、路径或通配符；留空允许任意 HTTP/HTTPS 主机。禁止在 URL 中携带用户名/密码，不自动跟随重定向。

凭据请求头示例：

```json
{"Authorization": "Bearer {{env:TAO_SERVICE_TOKEN}}"}
```

变量在 Runtime 启动时继承自环境，修改变量后重新启动 Tao。变量缺失时工具返回错误，配置中不需要填入真实密钥。当前没有凭据管理器。

## 4. 权限

组合规则包括“继承”“询问”“允许”“禁止”。自定义工具库另有询问/允许/禁止上限。

- 工具库或组合明确禁止时，无法通过会话完全放行覆盖。
- 工具库要求询问时，组合允许也仍需确认。
- 组合明确要求询问时，完全放行也仍需确认；用户可允许一次或本会话。
- 文件工具可以限制在工作区内，判断目标及其父目录的真实路径。
- 组合允许只放宽普通审计询问，不能覆盖禁止和工作区范围。

文件范围只约束列出的内置文件工具；任意程序、Shell、Extension 和 HTTP 调用没有操作系统沙盒。此批不宣称隔离任意代码。

手动工具测试是用户主动执行，询问工具可以直接测试，禁止工具不能测试；测试输出显示在定制页，不写入聊天。

## 5. 导入导出与迁移

通过右上角组合操作菜单导出当前组合 JSON，包含其引用的工具以及允许委派的目标组合（递归去重），常见凭据字段脱敏，环境变量引用保留。导入时重新映射组合 ID 和委派引用，避免误指向本机原组合。分享前检查脚本、提示词和参数是否包含私人信息。

左侧底部“导入组合”菜单支持文件或粘贴 JSON，合并到未保存草稿。同名同定义工具复用现有工具；同名不同定义会报错，需要先修改导入文件中的工具名。保存之前可检查权限并继续编辑。

首次使用自动把旧 `runtime/profile.json` 迁移为“默认助手”，原文件保留。新配置在 `%USERPROFILE%\.tao\agents\catalog.json`，会话快照在各会话 `conversation.json`。

## 子代理协作

1. 新建组合默认打开“允许委派子任务”，也可关闭。允许组合留空时使用继承当前配置的“默认成员”；需要不同角色时勾选指定组合。设置并发、任务总数、时长和模型轮次后保存。已有组合与会话保留原开关，旧数据缺省关闭。
2. 在聊天中选择这个组合；已有会话需点击“应用新版组合”。可以要求主智能体把几个独立任务交给指定组合，再核实结果并汇总。
3. 展开工作过程的记录查看各子任务状态。子代理要求确认时，权限框在主会话出现，并注明子任务名称。
4. 停止主请求会停止其子任务；主代理也可以调用工具停止单个子任务。主请求结束后回收尚未结束的子任务。

子代理的工具与权限取父子组合交集；“允许使用某组合”不等于允许其全部工具。自定义工具须有相同 ID 与实际定义；变更后的定义不能继承旧授权。子代理拥有独立上下文，但共享父工作区，当前没有文件系统沙盒或自动工作目录隔离。子代理暂不加载 Extension，也不递归委派。

同级现在可查看成员名册、定向分享发现和建议，也可以向主代理提问。普通消息在下一模型调用前进入接收方上下文，不会启动空闲成员；成员的取消建议不会直接停止对方。主代理可以为已有成员追加任务，忙时排队，新任务保留自己的状态并复用该成员的私有历史。成员可以停止自己，管理其他成员由主代理负责。

例如可以要求：“建立共享任务板，先检查基础信息，验收通过后再做后续检查；让成员按组合能力认领下一项，分享影响对方的发现，由你核实并验收。”主代理可登记共享任务和依赖，成员可预领一项后续任务，当前任务提交后串行执行；空闲成员由主代理显式分配启动。前置任务必须验收通过，下游才可认领。

主代理可以单独取消任务、核查已有文件或外部操作后重试，也可在任务获准组合内换成员。每项最多三次尝试，旧记录保留；已经发生的操作不会回滚，不会自动重放旧权限确认。展开工作面板的 Trace 可看到待认领、依赖状态、执行代次和消息投递状态。桌面任务概览目前只读，任务管理由智能体工具执行，详见 [多智能体设计](./11-多智能体第一版设计.md)。

## 6. 开发验证

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run test:agents
npm.cmd run test:ui
npm.cmd run tauri dev
```

`test:agents` 使用临时目录和本地模拟模型服务，不需要 API Key，不调用真实模型。覆盖组合隔离、版本变化、旧数据迁移、文件范围、输入校验、程序参数、HTTP 范围、超时、停止和重试。桌面交互与干净 Windows MSI 验收另外追踪。

只检查界面时运行 `npm.cmd run preview:ui`，打开 `http://127.0.0.1:1432/__ui_preview`；加 `?theme=dark` 预览深色。这个入口渲染实际 React 页面，数据和保存操作仅在浏览器内存模拟，不执行工具、不访问模型、不修改真实 Tao 配置；不代替桌面验收。

验证 Markdown 和滚动时，打开 `http://127.0.0.1:1432/__ui_preview?scenario=scroll`；加 `&theme=dark` 切换深色。该场景包含长历史、表格、代码和 160 条工作记录，发送任意消息会模拟一分钟流式输出和追加 Trace。可检查上滑保持、回到最新、切换会话位置恢复及文件预览；“停止生成”可提前结束模拟。

聊天（包括生成中的回答）与文件预览使用同一 Markdown/GFM 组件，支持表格、分隔线、嵌套列表、任务列表和代码复制；宽表/代码在自身区域滚动。主对话与右侧工作记录分别保存阅读位置，手动上滑后暂停跟随，点击“回到最新/最新记录”恢复。原始 HTML 不执行，图片引用保持说明占位，不自动加载远程资源。
