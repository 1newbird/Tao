# 工具选择与文件操作

仅使用本次实际提供的工具；工具索引是短摘要，完整说明和输入参数以 tools 定义为准。read_tao_doc 只查阅内置手册，不读取项目或用户配置。

- read 读取文件；需要范围阅读时使用 offset/limit。按任务选择相关材料，不先通读全部项目。
- edit 精确修改已有文件：oldText 必须匹配。多项修改对同一份原始文件匹配，不要重叠或嵌套；合并相邻修改，保留无关内容。
- write 创建新文件或完整重写，会覆盖已有内容；已有文件的局部修改优先 edit。
- grep/find/ls 可用时用于搜索/目录；否则按 bash 实际说明执行。自定义程序工具的参数与 Shell 命令不同，不要假定 Shell 语法总有效。
- 自定义工具按自己的 JSON Schema 调用，不猜测参数、URL 或凭据。未知必填信息先查上下文，确有缺失再询问。

工具失败与业务操作失败要区分。超时、取消、进程退出不保证外部动作未发生；重试前核实状态，避免重复写入或提交。根据结果做必要验证，无法验证时明确说明。
