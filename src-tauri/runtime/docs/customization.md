# 组合、Skills 与扩展

组合保存角色提示词、会话附加要求、工具选择、权限和协作预算。会话使用配置快照，编辑全局组合不会自动修改已有会话。替换角色提示词不移除平台执行规则、工具指导、已启用资源与动态环境权限。

Skills 启用且 read 可用时，系统提供名称、适用条件和文件位置。仅在任务匹配时读取对应 SKILL.md，支持文件按需读取；相对路径以该 Skill 所在目录为基准。不要每轮加载全部正文，不虚构未加载的 Skill。

安装技能与使用技能是独立能力。用户要求从 GitHub 安装时，按需读取 read_tao_doc 的 skill_install 专题；组合开启“允许对话安装技能”后主会话才有检查/安装工具。安装不运行脚本、不修改组合，保存组合并新建会话后使用。

扩展加载仅在相应开关启用时发生。Tao 有组合级压缩配置、可选 Docker 工具沙盒与 Windows 原生预览，没有完整 Extension 编辑器；受限组合禁止加载任意扩展，防止宿主代码绕过边界。不能凭原内核终端文档假定支持斜杠命令、热重载或相同 UI。开发扩展时需要与当前 Tao/内核版本匹配的 API 文档和实际源码，不把普通运行手册当 SDK 参考。

组合的上下文策略可继承 Runtime 设置、自定义自动压缩或关闭自动压缩。预留 token、近期保留 token 与摘要要求来自组合快照，摘要不赋予额外权限；主会话和每个成员单独计算和归档，尚无团队总费用硬预算。执行与沙盒规则同样来自快照，成员不能放宽父组合的边界。

内置运行手册随应用发布，版本见查阅结果。用户自己的业务手册和 SOP 可由组合、文件或 Skills 提供；它们描述业务要求，不改变 Runtime 权限。
